# AI Agents Lab

Долгосрочный проект персонального JARVIS: постепенно собираем систему из моделей, инструментов, памяти и интерфейсов. Каждый этап должен давать работающий и проверяемый результат.

Сейчас реализованы учебные примеры Python и HTTP, общий агент с терминальным и Telegram-интерфейсами, локальная память SQLite, реестр инструментов, MCP-сервер с клиентом и [Business Agent](08_business_agent/README.md) для подтверждаемого учёта доходов и расходов. Текущий статус и незавершённые этапы указаны в [roadmap](docs/ROADMAP.md).

## Запуск текущей локальной версии на Windows

Нужны Git и Python 3.11. Проверенная локальная версия — 3.11.9. Если `py -3.11 --version` не работает, установите Python 3.11 перед созданием окружения.

```powershell
if (-not (Test-Path .venv)) { py -3.11 -m venv .venv }
.\.venv\Scripts\python.exe -m pip install -r 03_first_agent/requirements.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Выполняйте команды из корня проекта. На новом компьютере после первой публикации получите папку так:

```powershell
git clone https://github.com/kurnevglebgenius/ai_agent_first.git
cd ai_agent_first
```

На 2026-09-15 нынешние модули и тесты ещё не отправлены на GitHub; до публикации `git clone` получит прежнюю версию.

Создайте локальную настройку, сохранив существующий файл, если он уже есть:

```powershell
if (-not (Test-Path 03_first_agent/.env)) {
    Copy-Item 03_first_agent/.env.example 03_first_agent/.env
}
```

В `03_first_agent/.env` задайте `OPENAI_API_KEY`, затем запустите:

```powershell
.\.venv\Scripts\python.exe 03_first_agent/main.py
```

Для выхода введите `exit`. Активация окружения не нужна: команды явно используют его Python. Тесты работают без ключа и без запросов к API. Настоящий диалог требует доступа к OpenAI API и может расходовать средства.

Для Telegram используйте отдельный `04_telegram_agent/.env` с `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_USER_ID` и `OPENAI_API_KEY`; запуск описан в [инструкции бота](04_telegram_agent/README.md). При старте бот создаёт понятное меню команд, а `/help` открывает краткую или тематическую справку. Короткие команды `/list`, `/summary`, `/money`, `/mail_report` и `/mail_reply` имеют обратную совместимость со старыми названиями. Локальные файлы `.env` не входят в Git. В каждом интерфейсе `MCP_ENABLED=true` подключает локальный MCP-сервер, `MCP_ALLOW_PUBLIC_NETWORK=false` оставляет четыре справочных сетевых инструмента выключенными. Примерные файлы `.env.example` по умолчанию отключают MCP; на этой рабочей машине он включён в локальных `.env`.

Подробности и вариант запуска через существующее окружение раздела: [03 First Agent](03_first_agent/README.md).

## API-пример Phase 2

Из корня проекта: `.\.venv\Scripts\python.exe 02_web_api/demo.py`. Команда сама запускает локальный учебный сервис, создаёт задачу через POST, читает её через GET и показывает обработку ошибок. Интернет и новые зависимости не нужны. Подробности: [02 Web/API](02_web_api/README.md).

Agent loop с калькулятором находится в shared/agent_runtime. Telegram — основной интерфейс, терминальный запуск раздела 03 сохранён.

Калькулятор и автоматическое сохранение фактов используют общий реестр с проверкой аргументов и разрешений: [Phase 6 — Tools](06_tools/README.md).

Локальный [MCP-сервер](07_mcp/README.md) через stdio публикует шесть инструментов только для чтения. CLI и Telegram могут использовать их через постоянное MCP-соединение; Codex зарегистрирован как ещё один клиент. Проверка без модели: `.\.venv\Scripts\python.exe 07_mcp/client.py check`. В новом сеансе Codex реально выполнен вызов `calculate_arithmetic` для 2 + 3.

С подключённой памятью реестр агента содержит 12 инструментов: шесть локальных расчётов и преобразований, поиск и запись фактов, четыре справочных сетевых GET. Сетевые инструменты доступны только при разрешённом сетевом режиме. Business Agent хранит данные отдельно от памяти и поддерживает категории, проекты, статусы оплаты, отчёты, бюджеты, исправления, мягкое удаление, шаблоны, CSV, зашифрованные backup, read-only анализ деловой почты и подтверждаемые SMTP-ответы. Быстрый локальный маршрутизатор не запускает бизнес-extractor для обычного разговора. Последний полный прогон и актуальный сценарий указаны в [его README](08_business_agent/README.md).

## Перед публикацией в GitHub

`origin` настроен, но текущий код ещё не закоммичен и не отправлен: в Git пока отслеживаются только четыре исходных файла. Перед будущим коммитом проверьте `git status --short`, список новых файлов `git ls-files --others --exclude-standard` и точный подготовленный diff `git diff --cached`. В `.gitignore` исключены `.env`, виртуальные окружения и `05_memory/data/`; проверка содержимого коммита всё равно обязательна. На этом компьютере `git user.name` и `git user.email` пока не заданы — перед первым коммитом укажите свои данные, не подставляя чужие. Коммит и push не выполняются автоматически. Правила — в [SECURITY](docs/SECURITY.md).
