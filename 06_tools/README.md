# 06 Tools

Единый реестр `shared/agent_runtime/tools.py` используется в CLI и Telegram.

| Инструмент | Разрешение | Область действия |
|---|---|---|
| calculate_balance | READ | Чистый расчёт выручки минус расходы |
| remember_fact | WRITE | Факты в подключённой сессии MemoryStore |
| calculate_arithmetic | READ | Сложение, вычитание, умножение, деление двух чисел |
| calculate_percentage | READ | Указанный процент от числа |
| days_between | READ | Разница двух календарных дат в днях |
| search_facts | READ | Поиск по названиям и значениям фактов текущей сессии |
| find_places | READ | До 5 городов с координатами, Open-Meteo / GeoNames |
| get_weather | READ | Текущая модельная погода по координатам, Open-Meteo |
| convert_currency | READ | Конвертация по справочному курсу Frankfurter с датой |
| search_wikipedia | READ | До 5 статей с описаниями и ссылками |
| convert_units | READ | Длина, масса, время и температура |
| summarize_numbers | READ | Сумма, среднее, медиана, минимум и максимум |

Каждый инструмент описан через ToolDefinition: схема, класс разрешения, лимит аргументов и обработчик. Перед исполнением ToolRegistry проверяет разрешение по имени и классу, размер UTF-8, корректность JSON, обязательные поля и строковые типы. Лишние и повторные ключи запрещены. Проверки сумм и источника факта остаются в существующих обработчиках.

Модель получает только схемы разрешённых инструментов. Незнакомые и запрещённые вызовы отклоняются даже при прямом запросе модели. Результат имеет поля `ok`, `value`, `error`; сырые исключения обработчика не передаются модели. Неудачные действия автоматически не повторяются. Лимит — три вызова за сообщение.

Автоматическая запись фактов включена при подключённой памяти. Для отключения передайте `FirstAgent(..., memory=memory, allow_memory_write=False)` в коде запуска. Чтение контекста и явные команды `/remember`, `/forget`, `/reset` сохраняют прежнее поведение: настройка ограничивает именно инструменты модели. Параметр пока не вынесен в `.env`.

Дополнительная защита: инструменты класса EXTERNAL и инструменты с `requires_confirmation=True` скрыты от модели и блокируются при вызове, даже если в grants выдано разрешение. Механизм подтверждения конкретного действия ещё не реализован, поэтому их нельзя запустить. Поле `confirmed` от модели не выдаёт согласия и отклоняется как лишний аргумент. При добавлении чувствительной записи или удаления разработчик обязан поставить `requires_confirmation=True`; класс WRITE сам по себе этого не определяет. Обычное сохранение фактов сохраняет проверку дословного источника и ограничения текущей сессии. Это граница вызовов, а не изоляция произвольного Python-кода.

Для нового инструмента добавьте схему плоского объекта обязательных строковых полей, обработчик и ToolDefinition в `default_tools`. Разрешение выдавайте отдельно для конкретного имени и класса. Другие виды схем сначала требуют расширения валидатора и тестов.

## Контракт каждого инструмента

Имя и описание находятся в schema, входные поля — в schema.parameters. Реестр проверяет обязательность непустого имени и описания, типы, структуру входа и размер. Предметная validation выполняется обработчиком до расчёта или чтения. Все результаты имеют `ok`, `value`, `error`; при успехе error равен null, при ошибке value равен null. Ошибки ввода новых инструментов объясняют, что исправить; неожиданные исключения заменяются общим сообщением без внутренних деталей.

Новые схемы и обработчики находятся в `shared/agent_runtime/utility_tools.py`:

| Имя | Вход | Validation | Пример value |
|---|---|---|---|
| calculate_arithmetic | operation, left, right | add/subtract/multiply/divide; ограниченные десятичные числа; запрет деления на ноль | `"0.3"` для 0.1 + 0.2 |
| calculate_percentage | base, percent | Ограниченные десятичные числа | `"31.25"` для 12.5% от 250 |
| days_between | start_date, end_date | Существующие даты строго YYYY-MM-DD | `{"days":2}` от 2024-02-28 до 2024-03-01 |
| search_facts | query | Непустая строка до 100 символов | `{"Город":"Минск"}`; `{}` при отсутствии совпадений |

Все входные значения — строки. Числа: необязательный минус, до 12 цифр целой части, до 6 после точки, без экспонент, пробелов, NaN и Infinity. Проценты могут быть отрицательными и больше 100. Деление использует 40 значащих цифр (округление ROUND_HALF_EVEN); инструменты не округляют автоматически до денежных копеек. Для разницы выручки и расходов остаётся calculate_balance с правилами денежных сумм.

Разница дат равна end_date − start_date: одинаковые даты дают 0, обратный порядок — отрицательное число; включительный подсчёт и часовые пояса не применяются. Поиск — подстрока без учёта регистра, только среди максимум 30 фактов подключённой сессии. SQL, пути к файлам и чужая сессия не принимаются. Поиск доступен и при отключённой автоматической записи.

## Как попробовать

После перезапуска CLI или Telegram попросите:

- «Посчитай 0.1 + 0.2».
- «Сколько составляет 12.5% от 250?».
- «Сколько дней между 2024-02-28 и 2024-03-01?».
- После `/remember город = Минск`: «Найди в памяти факты со словом Минск».

Выбор инструмента делает модель. Offline-тесты проверяют исполнение и передачу результатов через agent loop; живое распознавание этих запросов моделью отдельно не проверено.

## Ещё шесть инструментов: реализация по официальной документации

| Инструмент | Входная schema (все поля обязательные строки) | Проверки и результат |
|---|---|---|
| find_places | query | 2–100 символов; до 5 мест с названием, страной, регионом и координатами; при нескольких совпадениях выбор уточняется |
| get_weather | latitude, longitude | Числа в диапазонах ±90/±180; температура, влажность и ветер с единицами и временем UTC |
| convert_currency | amount, from_currency, to_currency | Неотрицательная сумма, разные трёхбуквенные валюты; сумма, курс, дата и источник |
| search_wikipedia | query, language | 2–200 символов; языки ru/en/de/es/fr; названия, короткие описания и ссылки, без полного текста статьи |
| convert_units | value, from_unit, to_unit | Только единицы одной размерности; температура не ниже абсолютного нуля; число и целевая единица |
| summarize_numbers | numbers | 1–100 десятичных чисел через запятую; count, sum, mean, median, min, max |

Каждая возможность содержит имя, описание, schema, validation, обработку ошибок и результат `{ok, value, error}`. Числовые ограничения такие же, как у предыдущих локальных инструментов. Decimal использует 40 значащих цифр. Поддерживаемые единицы: m/km/cm/mm/in/ft/mi, kg/g/lb, s/min/h, C/F/K. mi — международная сухопутная миля, lb — фунт массы. Среднее и деление могут округляться; автоматического округления валют до копеек нет.

Источники реализации, проверены 2026-09-14:

- [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api): поиск места, координаты и атрибуция GeoNames.
- [Open-Meteo Weather API](https://open-meteo.com/en/docs): current variables; текущие условия основаны на погодных моделях. Используется публичный endpoint для некоммерческого прототипа; для коммерческого запуска проверьте условия сервиса и тариф.
- [Frankfurter v1](https://frankfurter.dev/v1/): latest, base, symbols. Конвертация выполняется в нашем коде; курс справочный, дата может быть предыдущим рабочим днём. Поддерживаются не все валюты; неподдерживаемая валюта возвращает ошибку, не выдуманный курс.
- [MediaWiki REST API](https://www.mediawiki.org/wiki/API:REST_API/Reference): search/page, q, limit и User-Agent. Это поиск в Википедии, не общий поиск по интернету.
- [NIST: коэффициенты перевода](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b9): фиксированные коэффициенты единиц.
- [Python statistics](https://docs.python.org/3/library/statistics.html): mean и median с Decimal.

## Сетевые ограничения

`public_tools.py` использует только GET к фиксированным HTTPS endpoints Open-Meteo, Frankfurter и пяти языков Википедии. Модель не задаёт хост, путь, заголовки или произвольный URL. Параметры кодируются через urlencode; redirects запрещены. Таймаут сокета — 8 секунд, ответ — до 128 КиБ, повторов нет; это не строгий общий дедлайн сетевого запроса. HTTP 429, сеть, неверный JSON и неожиданная структура ответа дают структурированную ошибку без сырого тела сервера. Ключи и новые пакеты не нужны.

Эти GET классифицированы как READ публичных справочников; они передают сервису введённый город, координаты, валюты или поисковый запрос. Диалог и память автоматически не прикрепляются. `FirstAgent(..., allow_public_network=False)` полностью убирает сетевые tools и блокирует их вызовы. CLI и Telegram берут это значение из `MCP_ALLOW_PUBLIC_NETWORK` в своём локальном `.env` независимо от того, включён ли сам MCP; безопасный пример — `false`. Для Codex сетевой режим задаётся отдельно флагом `--allow-public-network` при запуске MCP-сервера. Класс EXTERNAL по-прежнему означает действия с последствиями и заблокирован. Публикации, отправки сообщений и удаления не добавлены.

Новый код: `shared/agent_runtime/public_tools.py` и `data_tools.py`. Демо не читает `.env` и не вызывает LLM:

```powershell
.\.venv\Scripts\python.exe 06_tools/demo.py
.\.venv\Scripts\python.exe 06_tools/demo.py --live
```

Первая команда проверяет локальные расчёты, вторая добавляет четыре реальных GET с нейтральными данными. Примеры сообщений боту после перезапуска: «Какая сейчас погода в Минске?», «Переведи 100 EUR в USD по последнему справочному курсу», «Найди в Википедии статьи про Python», «Переведи 5 миль в километры», «Найди среднее и медиану чисел 10, 20, 90».

Проверка из корня проекта: `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`. Проверяются запреты без исполнения, неверные аргументы, ошибки обработчиков, отключённая запись, схемы модели и прежняя работа агента. Новых зависимостей нет.
